# Customer & Sales Analysis using MySQL

## Project Overview

This project analyzes customer and sales data using MySQL.

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

## Database

The database contains:

- Customers
- Employees
- Products
- Sales

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Subqueries
- Aggregate Functions
- INSERT
- UPDATE
- DELETE
- Primary Key
- Foreign Key
- Constraints

## Analysis Performed

- Total sales analysis
- Average sales
- Highest and lowest sales
- Customer analysis
- Product analysis
- Category-wise sales
- Employee-wise sales
- Manager-employee relationships
- Customers with high sales
- Above-average sales transactions

## Conclusion

This project demonstrates relational database design and SQL-based business analysis using customer, employee, product, and sales data.
